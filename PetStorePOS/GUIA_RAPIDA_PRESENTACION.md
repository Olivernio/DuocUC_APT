## 🖥️ SECUENCIA DE DEMO

### Demo Funcional (2:30)
1. Página inicio → Diseño moderno (30s)
2. Catálogo → Buscar producto (30s)
3. Reseñas → Mostrar ratings (30s)
4. Carrito → Checkout (30s)
5. Dashboard → Estadísticas (30s)

### ⭐ Demo Accesibilidad (2:30) - CRÍTICO

#### Paso 1: Activar lector (30s)
- Activar NVDA (Ctrl+Alt+N) o VoiceOver (Cmd+F5)
- Dejar que se escuche el sonido
- "Esto es lo que usan las personas ciegas"

#### Paso 2: Navegación teclado (45s)
- Presionar Tab varias veces
- Lector anuncia: "Inicio, botón", "Productos, enlace"
- Presionar Enter en "Productos"
- Lector anuncia estructura semántica
- "Toda la información disponible para lectores"

#### Paso 3: Formulario (45s)
- Ir a login/registro
- Tab entre campos
- Lector anuncia cada campo claramente
- Mostrar mensajes de error (se anuncian automáticamente)

#### Paso 4: Modos accesibilidad (30s)
- Ir a `/accesibilidad/`
- Activar "Alto Contraste"
- Activar "Modo Daltónicos"
- Aumentar tamaño de fuente
